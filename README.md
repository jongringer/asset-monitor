## 데이터 소스 (브라우저에서 직접 호출)

- **지수·금**: Yahoo Finance `v8/finance/spark` — 브라우저에서는 CORS가 막혀 있어
  `r.jina.ai` → `codetabs` → `allorigins` → `cors.lol` → 직접 호출 순서로 폴백합니다.
- **가상자산**: CoinGecko → OKX → Upbit 순 폴백.

각 요청은 3.5~5.5초 타임아웃이고, 한쪽이 실패해도 나머지는 그대로 갱신됩니다.
2분 넘게 갱신되지 않은 값은 흐리게 표시되고, 10초마다 자동 재시도합니다.
