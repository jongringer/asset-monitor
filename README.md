## 장중 / 장마감 표시 (좌측 세로 바 · 맨 아래 동그라미)

## 삼성전자·SK하이닉스: 장중 현재가 ↔ 마감 후 예상가 자동 전환

한국 정규장이 열리면 그 두 행이 **네이버 증권 실제 현재가**로 바뀌고, 15:30이 지나면 다시 **KOSPILAB 해외 실시간 예상가**로 돌아갑니다. 1초마다 시장 상태를 다시 계산하므로 개장·마감·주말·휴장일 진입에 화면이 스스로 바뀝니다.

| 시각 | 행 이름 | 가격 | 전일 대비 | 좌측 바 |
|---|---|---|---|---|
| 09:00~15:30 평일(휴장일 제외) | `삼성전자` · `SK하이닉스` | 네이버 증권 현재가 | 네이버 `fluctuationsRatio` | 초록 |
| 그 외(마감 후·주말·휴장일) | `삼성전자 예상가` · `SK하이닉스 예상가` | KOSPILAB `priceKrw` | KOSPILAB `vsClosePct` | KOSPILAB 응답이 60초 안에 오면 초록, 끊기면 빨강 |

3년내 최고점 대비 변동률과 월별 미니 그래프는 **지금 화면에 떠 있는 가격**을 그대로 기준으로 다시 계산되므로, 장중에는 실제 현재가 기준, 마감 후에는 예상가 기준으로 자동 반영됩니다.

장중에 네이버 현재가를 못 받아오면 그 행은 마지막으로 받은 현재가를 흐리게(2분 경과) 두고 다음 10초에 재시도합니다(예상가로 섞어 바꾸지 않습니다).

**화면 미리보기(검증용)**: 주소 끝에 `?krmode=open` 또는 `?krmode=closed`를 붙이면 시간과 관계없이 해당 모드의 화면·데이터 경로를 그대로 볼 수 있습니다.

## 데이터 소스 (브라우저에서 직접 호출)

- **코스피·코스닥**: 네이버 증권 실시간 `https://polling.finance.naver.com/api/realtime/domestic/index/KOSPI,KOSDAQ`(7초 갱신, `closePrice`·`fluctuationsRatio`·`marketStatus`). Yahoo `^KS11`·`^KQ11`은 한국장 장중에 당일 봉을 만들지 않아 마지막 데이터가 **직전 거래일 종가**에 머물고 등락률도 그날 것이 되므로, 장중에는 이 소스만 쓴다(Yahoo 값은 장 마감·개장 전에만 보조로 사용). 이 API도 CORS 헤더가 없고 `Origin`을 실으면 403이 나서 `allorigins`·`jina`를 동시에 먼저 시도하고 codetabs·cors.lol·직접 호출로 이어지는 프록시 체인을 거치며, 매회 `?_=` 캐시버스터를 붙인다.
- **지수·금·원유·환율·SK하이닉스 ADR**: Yahoo Finance `v8/finance/spark` — 브라우저에서는 CORS가 막혀 있어
  `r.jina.ai` → `codetabs` → `allorigins` → `cors.lol` → 직접 호출 순서로 폴백합니다.
  심볼 10개(코스피·코스닥 제외)를 한 번의 요청으로 묶어 받습니다.
- **가상자산**: CoinGecko → OKX → Upbit 순 폴백.
- **삼성전자·SK하이닉스 (장중 현재가)**: 한국 정규장(09:00~15:30 KST) 중에는 `https://polling.finance.naver.com/api/realtime/domestic/stock/005930,000660`에서 `closePrice`(현재가)·`fluctuationsRatio`(전일 종가 대비 등락률)·`marketStatus`를 받아 `삼성전자`·`SK하이닉스` 행으로 표시합니다. 코스피·코스닥과 같은 프록시 체인을 쓰되 분당 호출 제한이 있는 `r.jina.ai`는 뒤로 미루고(allorigins+codetabs → cors.lol+jina → 직접) 성공한 조합을 다음 회에 우선합니다. 장중에는 이 요청 대신 KOSPILAB을 부르므로 두 소스가 같은 행을 두고 경합하지 않습니다.
- **삼성전자·SK하이닉스 (마감 후 예상가)**: `https://kospilab.com/api/prices` 한 번으로 두 종목의 해외 실시간 추정가(`computed.priceKrw`)와 전일 종가 대비 변동률(`computed.vsClosePct`)을 받습니다. 이 API는 CORS 헤더가 없어 같은 프록시 체인(`r.jina.ai` → codetabs → allorigins → cors.lol → 직접)을 거칩니다. `r.jina.ai`는 분당 20회 제한이 있어 10초 주기 조회(분당 6회)로 맞춰 두었습니다. 15:30이 지나면 다음 갱신(최대 10초)에 자동으로 예상가 소스로 넘어갑니다.
- **3년 히스토리(미니 그래프용)**: 같은 `v8/finance/spark`에 `range=3y&interval=1mo` — 16개 심볼(비트코인 `BTC-USD`, 이더리움 `ETH-USD`, 삼성전자 `005930.KS`, SK하이닉스 `000660.KS` 포함)을 **한 요청**으로 받고, 프록시는 한 번에 하나씩만 시도합니다. 실패하면 심볼별 `v8/finance/chart`로 천천히 보충합니다.

각 요청은 3.5~6초 타임아웃이고, 한쪽이 실패해도 나머지는 그대로 갱신됩니다.
2분 넘게 갱신되지 않은 값은 흐리게 표시되고, 10초마다 자동 재시도합니다.
