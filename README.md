## 자산명 옆 미니 그래프 (3년 주간)

- 각 행의 자산명과 현재가 사이에 폭 56px × 높이 20px 인라인 SVG 스파크라인을 그립니다.
- 세로축은 그 자산의 3년 구간 안에서 자동으로 맞추고(변동폭이 8%p 미만이면 8%p로 고정해 노이즈 증폭 방지), 맨 위 희미한 점선이 **최고점 = 0%** 입니다.
- 최고점 아래(하락 구간)는 블루·시안 계열, 최고점을 넘어선 구간은 레드 계열로 표시하고 현재 위치는 끝점 도트로 찍습니다.
- 3년 주간 종가를 `(종가 − 최고점) / 최고점 × 100`으로 바꿔 그리며, 10초 실시간 갱신에서는 **마지막 점만** 최신 변동률로 이어 그립니다.
- 히스토리는 페이지를 열 때 백그라운드로 **1회만** 받아오고(6시간 캐시), 일부가 실패해도 13개 실시간 수치 표시는 영향을 받지 않습니다.

## 데이터 소스 (브라우저에서 직접 호출)

- **지수·금·원유·환율·SK하이닉스 ADR**: Yahoo Finance `v8/finance/spark` — 브라우저에서는 CORS가 막혀 있어
  `r.jina.ai` → `codetabs` → `allorigins` → `cors.lol` → 직접 호출 순서로 폴백합니다.
  심볼 11개를 한 번의 요청으로 묶어 받습니다.
- **가상자산**: CoinGecko → OKX → Upbit 순 폴백.
- **3년 히스토리(미니 그래프용)**: 같은 `v8/finance/spark`에 `range=3y&interval=1wk` — 13개 심볼(비트코인 `BTC-USD`, 이더리움 `ETH-USD` 포함)을 **한 요청**으로 받고, 프록시는 한 번에 하나씩만 시도합니다. 실패하면 심볼별 `v8/finance/chart`로 천천히 보충합니다.

각 요청은 3.5~6초 타임아웃이고, 한쪽이 실패해도 나머지는 그대로 갱신됩니다.
2분 넘게 갱신되지 않은 값은 흐리게 표시되고, 10초마다 자동 재시도합니다.
